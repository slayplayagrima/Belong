Build a modern, clean, and emotionally warm landing (hero) page for a web application called "KindNest" (a centralized adoption platform for animals and child adoption awareness in India).

Use:

* React (with TypeScript)
* Tailwind CSS
* Functional components only

Design requirements:

1. 🌱 Overall Theme:

* Light, soft, and friendly UI
* Use pastel colors (peach, soft blue, mint)
* Background: warm off-white (#FAFAF7)
* Rounded corners (16px–24px)
* Soft shadows (not harsh)
* Avoid dark theme and avoid strong contrast

---

2. 🎯 Hero Section Layout:

Create a full-screen hero section with:

LEFT SIDE:

* Heading (large, friendly font):
  "Find a home. Give a life."

* Subheading:
  "Discover animals in need of love and connect with trusted NGOs across India."

* Primary CTA button (prominent):
  "Start Your Journey"

* Secondary CTA (subtle text button below or beside):
  "Register as NGO"

RIGHT SIDE:

* A soft illustration or image collage of pets (dogs/cats) with rounded shapes
* Optional: subtle floating cards showing animal previews

---

3. 🧠 UX Behavior:

* Clicking "Start Your Journey" → navigate to "/role-select"
* Clicking "Register as NGO" → navigate to "/ngo/register"

Use React Router for navigation.

---

4. 🎨 Styling Details:

* Buttons:

  * Primary: soft peach background (#FFB7A5), rounded-full, slight hover scale
  * Secondary: text button, muted color

* Typography:

  * Clean font (Inter or Poppins)
  * Large spacing between elements

* Layout:

  * Center vertically
  * Responsive (stack on mobile)

---

5. 🧩 Components:

Create:

* Navbar (logo + minimal nav)
* HeroSection component
* Button component (reusable)

---

6. 📱 Responsiveness:

* Desktop: split layout (text left, image right)
* Mobile: stacked layout (text above image)

---

7. ✨ Feel:

The page should feel:

* Safe
* Friendly
* Trustworthy
* Emotional but not overwhelming

Inspired by:

* Duolingo friendliness
* Modern nonprofit platforms
* Clean startup landing pages

---

Output:

* Clean, readable React + Tailwind code
* Proper component structure
* No unnecessary complexity
